usage -->

input_string -->

hello world.com_health care app_facebook app

expected output -->

{
[
{
"website":"hello world.com"
},
{
"mobile app":"health care app"
},
{
"facebook application":"facebook app"
}
]
}

important note !!!--> Items are separated by _ (underscore). First part is website, second is mobile app, third is facebook application.


english preference -->

input_string -->

1

expected output -->

{
"english preference":"American English"
}

important note !!!--> "1" = American English, "0" = British English


use and description -->

input_string -->

yes_management lab*just kidding brother

expected output -->

{
[
{
"confirmation":"yes",
"use_case":"management lab",
"description":"just kidding brother"
}
]
}

important note !!!--> confirmation and use_case separated by _ (underscore), use_case and description separated by * (asterisk)
