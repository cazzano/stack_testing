## Quick Reference: Delimiter Meanings

### Third-Party Services:
- `_` = Separates categories
- `#` = Separates services within a category  
- `$` = Separates provider from service
- `^` = Separates flags
- `*` = Starts "Other" category

### AI Services:
- `_` = Separates items in each section
- `#` = Separates functions from platforms
- `*` = Separates before opt-out methods

### Online Payments:
- `#` = Separates vendor name from URL
- `_` = Separates vendors
- `*` = Separates before additional details
